# Where do model results live?

Raw files live on Azure, in JSON and parquet format. We are working towards deprecating the JSON format.

Visualisations and summaries of results are displayed in the [outputs app](https://connect.strategyunitwm.nhs.uk/nhp/outputs/) for end users

# How do I access and work with model results?

If using R: Use [{azkit}](https://github.com/The-Strategy-Unit/azkit) and [{reskit}](https://github.com/The-Strategy-Unit/nhp_reskit)

For Python: We have some useful functions in nhp_products
